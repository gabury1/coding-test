# 배낭 문제 (Knapsack)

## 핵심 개념

**아이템을 선택해서 최적값을 구하는 DP**

- 각 아이템은 무게(비용)와 가치를 가짐
- 제한 조건 안에서 최대/최소를 구함

---

## 가장 중요한 판단: 축을 어떻게 잡을까?

> **"구하려는 값이 너무 크면 축을 뒤집어라!"**

| 문제 | dp 축 | dp 값 | 답 |
|------|-------|-------|-----|
| 평범한 배낭 | `dp[무게]` | 최대 가치 | `dp[W]` |
| 앱(7579) | `dp[비용]` | 최대 메모리 | `min(k where dp[k] >= M)` |

### 왜 축을 뒤집나?

- 평범한 배낭: 무게 최대 100,000 → 배열 크기 OK
- 앱 문제: 메모리 최대 10,000,000 × 100개 → 배열 크기 10억 → 불가!
- 비용은 최대 100 × 100 = 10,000 → OK

**→ 배열 크기가 작은 쪽을 축으로 잡아야 한다!**

---

## 유형별 정리

### 1. 0/1 냅색 (기본)
- 각 아이템을 최대 1번만 사용
- **역방향 순회** (큰 인덱스 → 작은 인덱스)
- 역방향인 이유: 같은 아이템을 두 번 쓰는 걸 방지

```python
dp = [0] * (W + 1)
for w, v in items:
    for j in range(W, w-1, -1):  # 역방향!
        dp[j] = max(dp[j], dp[j-w] + v)
```

### 2. 언바운디드 냅색 (동전 문제 등)
- 각 아이템을 여러 번 사용 가능
- **순방향 순회** (작은 인덱스 → 큰 인덱스)
- 순방향인 이유: 같은 아이템을 여러 번 써도 됨

```python
dp = [0] * (W + 1)
for w, v in items:
    for j in range(w, W+1):  # 순방향!
        dp[j] = max(dp[j], dp[j-w] + v)
```

### 3. 축 뒤집기 (앱 문제 등)
- 구하는 값이 너무 크면 축과 값을 바꿔라

```python
# dp[비용] = 최대 메모리
dp = [0] * (총비용 + 1)
for c, m in items:
    for j in range(총비용, c-1, -1):
        dp[j] = max(dp[j], dp[j-c] + m)

answer = min(j for j in range(총비용+1) if dp[j] >= M)
```

## 판별 체크리스트

1. **아이템을 중복 사용 가능한가?**
   - 불가 → 역방향 순회 (0/1 냅색)
   - 가능 → 순방향 순회 (언바운디드)

2. **dp 배열 크기가 너무 커지지 않는가?**
   - 너무 크면 → 축을 뒤집어라!
   - `dp[무게] = 최대가치` vs `dp[가치] = 최소무게`

3. **최대를 구하는가, 최소를 구하는가?**
   - 최대 → `max(dp[j], dp[j-w] + v)`
   - 최소 → `min(dp[j], dp[j-w] + v)`, 초기값 `float('inf')`
